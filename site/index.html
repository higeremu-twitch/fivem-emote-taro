FiveM × Stream Deck

FiveMエモート太郎

エモート専用のプロファイルを作りましょう。

Stream Deck の各機種に合わせた配列に、自分の好きなエモートを事前登録。 出力したファイルでそのまま実装できます。

ボタンを押すと、送られる文字が出ます  

↑ 作ったものが Stream Deck にこう並びます。押すと、そのボタンが送るコマンドが出ます。

調べて、控えて、打ち込む

あの人が使っているエモート。街で見かけたエモート。配信で見かけたエモート。 自分も使おうと思って設定する時、綴りとか忘れちゃいますよね？スペルミスすると動作もしません。配信中に設定する訳にもいきません。

FiveMエモート太郎は事前にあなたのエモートのプロファイルを作成できます。 お使いの機種に応じて好きな数だけ設定可能です。フォルダ分けにも対応。手順もとっても簡単です。

気になるエモートコマンドは事前に控えておきましょう。

種類で絞る

動作・小道具・ダンス・歩き方・表情・2人でやる。用途に合わせて絞り込めます。

まとめて置く

チェックを付けて「選択分を一括配置」。入り切らない分は自動でページが分かれます。

綴りは確定済み

選んだ時点でコマンドが決まります。チャット欄の呼び出しとエモートのコマンドを同時に登録。

物理ボタンでもバーチャルボタンでもOK

書き出し先は物理ボタンだけではありません。スマホアプリ（Stream Deck Mobile）や、 PC上に表示させるタイプ（Virtual Stream Deck）にもそのまま入ります。 実機を持っていなくても、アプリを準備すれば今日から使えます。

並べた内容は機種に縛られません。実機で組んだものをそのままスマホアプリへ、 スマホアプリで組んだものを実機へ。キーの数が違っても、 ページの分かれ方が計算し直されるだけで、中身はそのまま残ります。 作り直す必要はありません。

登録方法

設定する機種を選ぶ

画面のいちばん上、左端です。実機・スマホアプリ・PC上に表示させるタイプ、どれでも構いません。 キー数を自分で決める機種（スマホアプリなど）を選ぶと、 そのとなりに縦横を入れる欄が出ます。

お使いの機種 Stream Deck / MK.2 — 15キー (5×3) 5×3 = 15キー

ゲーム画面のコマンドを、そのまま貼り付けても引けます。 一覧にないオリジナルのエモートもその綴りのまま登録ができます。選択肢になくてもご安心ください。 歩き方や表情のコマンドが画面に出ない街では、ゲーム内で /walks /moods と打つと一覧がチャットに出ます。

ボタンを配置する

対象エモートをクリックをすると空いている所に入ります。位置を決めたいときはドラッグ。 ボタンをダブルクリックすると名前を変えられます。複数のチェックボックスを入れて一括で流し込むことも可能です。

入れる左の一覧をクリック／ドラッグ
まとめる「フォルダを追加」。中に入れれば階層になります
入り切らない分自動で「つづき →」が付き、次のページに続きます
戻る2ページ目以降には「← 戻る」が自動で入ります

書き出して、ダブルクリック

右上の「書き出す」を押すと、ファイルがダウンロードされます。 そのファイルをダブルクリックするだけで Stream Deck に入ります。

読み込む 全消去 書き出す（.streamDeckProfile）

このファイルが作業データそのものです。別にバックアップを取る必要はありません。

行き来するボタンを付ける

登録しただけでは、すでに設定している元のプロファイルと行き来できません。 Stream Deck アプリで空きボタンを2つ使い、 「プロファイル切り替え」を往復ぶん置いてください。

行きエモート用プロファイルへ行くボタンを設置
戻り元のプロファイルへ戻るボタンを設置

この設定は1回だけです。エモート太郎で読み込み直しても、 このボタンはそのまま残ります。

※ 行き先はパソコンごとに決まる番号で指定するため、本ツールでは作れません。 設定ボタンは Stream Deck アプリにてご確認ください。

プロファイルは入れ直すと増えます

取り込みは上書きではありません。同じものを2回入れると「◯◯ コピー」ができます。 古い方はアプリの一覧から消してください。

動物用は別枠です

犬や猫のときだけ動くエモートが登録されています。人間のキャラでは1件も動かないので、 チェックで切り替える形にしています。

再読み込みで編集できます。

編集したいプロファイルは、書き出したファイルを「読み込む」に渡してください。 エモート以外のキーが入ったプロファイルは、受け付けません。

本ツールのデータは rpemotes-reborn ／ dpemotes （ともに GPL-3.0）に登録されているエモート一覧を反映しています。

FiveM で制作されている街によって入っているエモート、入ってないエモートが存在します。 またエモート自体は登録されていても動作をしない場合もありえます。

ですので、設定して動かない場合もあるのでご容赦ください。

なお、本ツールのリストにはないエモートコマンドは検索時に該当がなければ直接登録して設定が可能です。

本ツール内ではボタンへの画像設定は行えません。詳細の調整は Stream Deck アプリ内で行ってください。
