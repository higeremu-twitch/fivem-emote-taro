# FiveMエモート太郎

FiveM のエモートを Stream Deck のボタンに流し込むための管理画面。
（フォルダ名・リポジトリ名は `fivem-deck-builder` のままです）
エモートを選ぶ → 並べる → `.streamDeckProfile` を書き出す → ダブルクリックで入れる。

ボタンの中身は毎回これ：

```
ホットキー T を押す  →  "/e dance" と入力  →  Enter
```

---

## 使い方

### 1. 開く

`index.html` をダブルクリック（Chrome / Edge どちらでも）。
サーバーもインストールもネット接続も不要 — エモート 1,851 件ごと 1 ファイルに埋め込んであります
（外部ファイルを一切読まないので、どこに置いても、どう開いても動きます）。

画面は**2列**です。左が探すところ、中央がデックです。

```
機種  名前                      [読み込む] [全消去] [詳細] [書き出す]
├─────────────┬──────────────────────────────┤
│ 種類のチェック │ ルート                        │
│ 検索          │ [フォルダを追加] ページ／件数    │
│ エモート一覧   │        デックの絵             │
└─────────────┴──────────────────────────────┘
```

機種の説明・入れかた・出典は **`詳細` を押したときだけ**右に出ます。
普段は中央を広く使うためで、XL（32キー）でも窮屈になりません。
**キー数を自分で決める機種**（Mobile / Virtual / 一覧にない機種）を選んだときは、
入力欄がそこにあるので**自動で開きます。**

### 2. 探して置く

各行は**名前と、実際に打ち込まれるコマンド**だけです。

```
Sit Chair - Tablet
/e sitchairf7
```

マウスを乗せても、この2つ以上は出ません。

### 種類をチェックしてから、綴りで探す

```
□ 動作 680     □ 小道具 648   □ ダンス 136
□ 歩き方 139   □ 表情 38      □ 2人でやる 94
[ 綴りだけ入れてください ]
```

**この6つは打つコマンドそのもの**（`/e` `/e` `/e` `/walk` `/mood` `/nearby`）で、どれになるかは
意見ではなく事実です。街のエモートメニューも同じ分かれ方をしているので、
ゲームから戻ってきた時点でどれかは分かっています。何もチェックしなければ全部が対象です。

検索欄には**綴りだけ**入れてください。`/e` を打つ必要はありません。

| 打つもの | 結果 |
|---|---:|
| `dance` | 119 |
| `Alien`（歩き方にチェック） | 1 |
| `hug`（2人でやるにチェック） | 8 |

**ゲーム画面のコマンドをそのまま貼っても引けます。**多くの街ではメニューで選んだ項目の下に
実際のコマンドが出るので、それをコピーしても構いません。

```
Sit With Me             ← メニューで選んでいるもの
/nearby (sitwithmepose) ← その下に出るコマンド。これを貼っても引けます
```

### 街によって見え方が変わります

2つの街で実測したところ、こう違いました。

| | 街A | 街B |
|---|---|---|
| エモートの名前 | **英語のまま** | **日本語に翻訳済み** |
| コマンドの表示 | 選んだものの下に出る | 名前の補足として出る |
| 歩き方・表情 | 出る | **コマンドが出ない**（動きはする） |

**変わるのは見せ方だけで、打つコマンドは同じ**です。だから登録されているエモート一覧が役に立ちます。

- **名前が日本語の街** — 画面に出ているコマンドの方を読んでください
- **歩き方・表情のコマンドが出ない街** — **ゲーム内で `/walks` `/moods` と打つと、
  一覧がチャットに出ます。**その街に入っているものがそのまま並ぶので、これがいちばん確実です。
  登録されているエモート一覧から探しても構いません
  （`/walk` 139件・`/mood` 38件は、実際に動くことを確認済みです）

打った文字に近い順（完全一致 → 前方一致 → 部分一致）に並びます。並び順は
`名前順（A→Z）` が既定で、`Z→A` と `登録順` も選べます。

**該当が0件のときだけ「そのまま登録」が出ます。** ゲーム内メニューで見た名前を打って何も出なければ、
その街だけのエモートです。出てきたボタンを押すと、コマンドと表示名を確かめてから登録できます。
（候補が並んでいる横にも出していた時期がありますが、正規の候補と紛らわしいのでやめました）

### 動物用は切り替えです

```
□ 動物用だけ表示   （OFF）1,735件 ← 人間のキャラ用
☑ 動物用だけ表示   （ON）   116件 ← 犬・猫のキャラ用
```

**混ざりません。**動物用は人間のキャラで**1件も動かず**（実機で確認）、逆も同じなので、
どちらか一方だけを見る形にしてあります。

### 行に出るのは1つだけ

| バッジ | 意味 |
|---|---|
| [小道具] | 何か持つ動作（傘・カップ・タブレット等）。打つのは `/e` |
| [ダンス] | 踊る動き。打つのは `/e` |
| [歩き方] | 歩く姿勢が変わります。戻すまで続きます。打つのは `/walk` |
| [表情] | 顔の表情が変わります。戻すまで続きます。打つのは `/mood` |
| [2人でやる] | 相手が必要。近くに誰もいないと「相手がいない」と出ます。打つのは `/nearby` |
| 無印 | 手ぶらの動作（動作カテゴリの大部分）。打つのは `/e` |

**これ以外の表示は全部やめました。**

- **意味タグ**（座る・タブレット等）— GTA の内部名へのキーワード一致で、
  1,421件中878件は正しさを確認できませんでした（`High` は `mood_dancing_high_1` なので
  「ダンス」と付きましたが、踊りません）
- **高互換 / 動き違 / どこでも使いやすい** — 「他の街でも通りそう」という**予測**でした。
  街のメニューで見て登録する流れでは、その街に在ることは既に確認済みです
- **止めるまで続く** — 元データの `LOOP` を私がそう読んだだけで、**確かめていません**。
  今は表情・歩き方の性質で説明しています
- **車の中だけ / 車の外だけ** — 事実ですが、44行だけ札が付くと特別扱いに見えます。
  動かない場面があるのは当たり前のことです
- **マウスオーバーの内部情報** — 小道具のモデル名やアニメーション辞書は、
  事実ではあっても読んで分かるものではありません

判定に使ったデータ（`Seen` / `Total` / `Drifted` / `Flag` / `vehicleRequirement`）は
`data\emotes.json` にそのまま残っています。**表示をやめただけで、捨ててはいません。**

### 成人向けは入っていません

一覧の作者が `AdultAnimation` と指定している30件は、**生成の時点で除いています。**
チェックで出す仕組みもありません（配るファイルに入れない、という判断です）。
`data\emotes.json` には残っているので、`tools\make-data.ps1` の1行で戻せます。

### 同じ名前で別のものが2つある場合があります

```
Handshake  [2人でやる]  /nearby handshake   ← 相手と握手する
Handshake               /e handshake        ← 1人で握手の動作をする
```

Lua の `RP.Shared` と `RP.Emotes` の両方に `handshake` があるためで、**別物として正しい**です。
同種のものが17件あります（`/mood Drunk` と `/walk Drunk`、`/walk Cop` と `/e cop` など）。
このツールは**コマンド＋名前**を鍵にしているので混ざりません。

**街のメニューでも別々に並んでいることを確認しました**（2人でやる方と、1人でやる方が独立して存在）。
名前だけで突き合わせていたら1つに潰れていた組み合わせです。

### 3. どこから来た一覧か

**FiveM 本体はエモートを1つも持っていません。**
同梱リソースは `citizen\resources` の `icons` だけで、`/e` はすべてコミュニティ製リソース由来です。
街ごとに入れているものが違うので、「FiveM のエモート一覧」というものは存在しません。

同梱の 1,851 件は **`alberttheprince/rpemotes-reborn`（現行）** から作っています。
`andristum/dpemotes`（原典）とも突き合わせてあり、その結果は
`data\emotes.json` の `Seen` / `Total` / `Drifted` に入っていますが、**画面には出していません。**

| リポジトリ | 位置づけ | ★ | フォーク | 最終更新 | 件数 |
|---|---|---:|---:|---|---:|
| `andristum/dpemotes` | **原典** | 144 | **295** | 2024-05-22 | 531 |
| `alberttheprince/rpemotes-reborn` | **現行** | 156 | 98 | 2026-08-14 | 1,899 |

（GitHub API 実測、2026-08-27。原典は更新が止まっているだけで、
`archived: false`・移行案内なしで**非推奨ではありません**）

一時は「両方にある＝どの街でも通りやすい」を **高互換** バッジで出していましたが、やめました。
**予測だったからです。**実際の使い方は「街のメニューで見たものを登録する」で、
その時点でその街に在ることは確認済みです。稼働中のサーバーで画面に出た23件のうち**22件が同梱にありました** —
予測（467件）より現実の方が広いという結果でした。

再計算は `tools\build-common.ps1`（`data\sources\*.lua` を突き合わせ）。データは残してあるので、
必要になれば表示を戻せます。

### 4. 並べる

| やりたいこと | 操作 |
|---|---|
| 空いてる所に入れる | 左のエモートをクリック |
| 場所を指定して入れる | 左からグリッドへドラッグ |
| 位置を入れ替える | ボタン同士をドラッグ（機種をまたいでも構成は保たれます） |
| ラベルを変える | ボタンをダブルクリック |
| 消す | ボタン右上の ✕ |
| フォルダを作る | 「フォルダを追加」→ フォルダをクリックで中に入る |
| まとめて入れる | 左でチェック → 「選択分を一括配置」 |
| 一覧に無いものを入れる | 検索欄に綴りを打つ → 「そのまま登録」 |
| ダイヤルに割り当てる | ダイヤル付き機種を選ぶとグリッド下に現れます |
| 前の続きから直す | 「読み込む」→ 書き出した `.streamDeckProfile` を選ぶ |

入り切らない分は「つづき →」が自動で入り、**戻れるページには必ず「← 戻る」が入ります。**

| どのページか | 「← 戻る」 | 押すと |
|---|---|---|
| いちばん最初の1枚 | **入りません** | 戻る先がないため |
| 2枚目以降 | 入ります | **前のページ**へ |
| フォルダの1枚目 | 入ります | 1つ上へ |

**機種を変えても中身は消えません。**構成は列や行を知らない形で持っていて、
ページ割りだけを機種ごとに計算し直すためです（50個の構成が Mini では11ページ、XL では3ページになります）。

### 5. 書き出す

「書き出す（.streamDeckProfile）」。ダウンロードフォルダに落ちます。

**このファイルが作業データそのものです。** 別途のバックアップはありません
（以前あった `バックアップ` ボタンは、読み込みができるようになったので外しました）。
キー・フォルダ・並び順・ダイヤル・機種・プロファイル名・チャットキー、
そしてデック側で付けたアイコンまで、このファイル1つに入っています。

### 6. 入れる

**落ちてきた `.streamDeckProfile` をダブルクリックするだけです。** Stream Deck が取り込みます。

これは [SDK に明記された公式手順](https://docs.elgato.com/streamdeck/sdk/guides/profiles/)で、
アプリのデータフォルダには一切書き込みません。要らなくなったらアプリのプロファイル一覧から削除できます。

**取り込みは上書きしません（2026-09-01 実機で確認）。** 同じファイルをもう一度入れると、
`◯◯ コピー` という名前で**別のプロファイルが増えます**。直したものを入れたら、
**古い方はアプリの一覧から手で消してください。**Stream Deck にプロファイルを統合する機能はありません。

**機種の指定は行き先を決めません。** MK.2（`20GAA9902` / 5×3）用に書き出したものを取り込んだところ、
繋がっている Stream Deck +（`20GBD9901` / 4×2）に割り当てられました。
ツールの機種選択は**並べ方の目安**であって、どのデックに入るかの指定ではありません。

### いつものプロファイルと行き来できるようにする（取り込み後に1回だけ）

**登録しただけでは、いつものプロファイルと行き来できません。**取り込んだプロファイルは
それ単体で置かれるので、**入る道も、戻る道も無い**状態です。Stream Deck アプリで
空きキーを2つ使い、「プロファイル切り替え」を**往復ぶん**設定してください。

```
行き（いつもの → エモート用）
1. Stream Deck アプリで、いつも使っているプロファイルを開く
2. 空いているキーに「プロファイル切り替え」を置く
3. 行き先に、取り込んだエモートプロファイルを選ぶ

戻り（エモート用 → いつもの）
4. 取り込んだエモートプロファイルを開く
5. 空いているキーに「プロファイル切り替え」を置く
6. 行き先に、いつも使っているプロファイルを選ぶ
```

**この設定はこのツールでは作れません。**切り替え先はプロファイルの ID で指定するのですが、
その ID はそれぞれのパソコンでプロファイルが作られたときに決まるもので、
書き出す側からは知りようがないためです。
（ID を空にしたキーを入れて試したところ、**Stream Deck はそのキーごと捨てました**）

**設定するのは1回だけで済みます。** このキーは読み込みでそのまま保持され、
書き出すときに行き先ごと書き戻されるので、**何度編集しても消えません。**

### 7. 直す

**書き出した `.streamDeckProfile` を「読み込む」に渡すと、続きから直せます。**
Stream Deck 側から書き出したものでも構いません。

読み込むのは**このツールで作ったプロファイルだけ**です。扱えるのは次の5種類で、
それ以外のキーが1つでもあると断ります。

| 扱えるキー | |
|---|---|
| エモート | このツールが作る本体 |
| フォルダ／戻る／つづき | 並べたときに自動で入る |
| **プロファイル切り替え** | 取り込み後にアプリで足す「いつものに戻る」キー |

音量ダイヤルやプラグインのキーが入ったプロファイルを読み込んで書き出すと、
**そのキーが消えてしまう**ので断っています。普段使いのプロファイルを編集する道具ではありません。

読み込むと機種も一緒に戻りますが、**構成として読むので機種は変えられます。**
15キー用に作ったものを読み込んで、Mini で並べ直せます。

ひとつだけ欠けます。ボタンの表示名は書き出すときに改行が入るので、戻すと
`Sunbathe - Hand On Head` が `Sunbathe Hand On Head` になります。送るコマンドは正確です。

書き出したファイルが本物のエクスポートと同じ形かは、機械で確認できます：

```powershell
cd tools    # このREADMEのあるフォルダから
.\verify-export.ps1 -Generated "$env:USERPROFILE\Downloads\FiveM_Emotes-xxxxxxxx.streamDeckProfile"
```

`STRUCTURE MATCHES` と出れば、構造・BOM・RequiredPlugins まで手本と一致しています。

**機種の紐付けは UUID ではなく型番です。** 本物のエクスポートを調べたところ、Stream Deck は
書き出すときに `Device.UUID` を**その場で作った別の GUID に差し替えて**いました。
実機のシリアルは要らず、`package.json` の `DeviceModel` だけで機種が決まります。
だから**他の人にもそのまま配れます**。

## 一覧を書き出して手で分類する

ジャンルは元データに存在しません。Lua には7つの区分しかなく、アニメーション辞書は
753種の接頭辞のうち561種が1件だけで、体系になっていません。名前から当てるのも失敗済みです。
**誰かが動きを見るしかない**ので、そのための表を出せます。

```powershell
cd tools    # このREADMEのあるフォルダから
.\make-classify-sheet.ps1
```

`data\emotes-classify.csv`（1,881行）が出ます。A列 `分類` が空欄なので、そこに書き込みます。

- **名前の語幹順**に並んでいるので `sunbathe1〜4` のような変種は隣接します（978グループ）
- C列 `コマンド` が戻すときの鍵なので、**この列は編集しないでください**
- 候補は**あえて入れていません**。先回りして埋めると確認せずに受け入れてしまい、
  消したヒントタグと同じ失敗になります。代わりに `手がかり` 列に辞書内の語をそのまま出しています
- UTF-8 BOM付きなので Excel でも Google スプレッドシートでもそのまま開けます

分類を画面に反映する仕組みは**まだありません**（埋まってから作ります）。

## エモート表を差し替える

左上の `＋` から。2通り。

**① rpemotes 形式の `AnimationList.lua` を読ませる**
ブラウザ内で解析します。`RP.Emotes` / `Dances` / `PropEmotes` / `Shared` /
`AnimalEmotes` / `Walks` / `Expressions` に対応。

**② ゲーム内の「お気に入り」から取り込む（いちばん確実）**

英語名の一覧から選ぶのは、動きを知らないと無理です。ゲーム内なら**見えます**。
なのでエモートメニューの「お気に入り」で★を付けてから、これを実行：

```powershell
cd tools    # このREADMEのあるフォルダから
.\import-favorites.ps1
```

`名前 | 日本語ラベル | /e` の形で出てくるので、そのまま `＋` の手打ちリストに貼れます。
**この街の日本語名も独自エモートも、そのまま入ります。**

保存場所は FiveM のソースで確認済み（[KVScriptFunctions.cpp](https://github.com/citizenfx/fivem/blob/master/code/components/citizen-resources-client/src/KVScriptFunctions.cpp)）：

| | |
|---|---|
| ストア | LevelDB `fxd:/kvs/` ＝ `%APPDATA%\CitizenFX\kvs` |
| キー | `res:<リソース名>:<キー>` → `res:rpemotes-reborn:rpemotes_favorites` |
| 値 | `{ "エモートID": { "label": "表示名" } }` |

`SetResourceKvpNoSync` で書かれるので、**ゲームを正常終了してから**実行してください。
`-List` で店の全キー、`-Key <キー名>` で任意の値を覗けます。

**③ 手打ちリストを貼る**

```
dance | ダンス | /e
sit3
Alien | エイリアン歩き | /walk
```

表示名とコマンドは省略可（既定 `/e`）。`#` で始まる行はコメント。

## デックの選択

現行ラインナップを全機種そろえてあります。**実機 → バーチャル → その他 → 未対応**の順です。

一時期、作った人のパソコンが知っている機種に **✓** を付けていましたが、やめました。
**ブラウザから接続機器は見えない**ので、あれは作った時点の測定結果を焼き込んだだけのもので、
他の人が開いても**その人の機種ではなく作った人の機種に印が付く**代物でした。
おまけに実機のシリアル番号まで一緒に埋め込んでいたので、配るには不適切でした。
機種は自分で選んでください。

| 機種 | 列×行 | キー | ダイヤル | 型番 |
|---|---|---:|---:|---|
| Stream Deck / MK.2 | 5×3 | 15 | — | `20GAA9902` |
| Stream Deck Mini | 3×2 | 6 | — | `20GAI9901` |
| Stream Deck Neo | 4×2 | 8 | — | `20GBJ9901` |
| Stream Deck XL | 8×4 | 32 | — | `20GAT9902` |
| Stream Deck + | 4×2 | 8 | 4 | `20GBD9901` |
| Stream Deck + XL | 9×4 | 36 | 6 | `20GBX9901` |
| Stream Deck Studio | 16×2 | 32 | 2 | **未確認** |
| Stream Deck Pedal | 3×1 | 3 | — | **未確認** |
| GALLEON 100 SD | 3×4 | 12 | 2 | `GRETSCH` |
| Stream Deck Mobile | 自由 | 1〜64 | — | `VSD2/WiFi` |
| Virtual Stream Deck | 自由 | 〜64 | — | `UI Stream Deck` |

列×行の出所は [python-elgato-streamdeck](https://github.com/abcminiuser/python-elgato-streamdeck) の
デバイスクラス（`KEY_COLS` / `KEY_ROWS`）で、キー数は
[Elgato 公式の比較ページ](https://www.elgato.com/us/en/explorer/products/stream-deck/stream-deck-device-comparison/)と全機種一致します。
型番はアプリ同梱の初期プロファイルが宣言している値です。

**Studio と Pedal は実機で試していません。** キーの並びが合わない可能性があります。
その機種でエクスポートを1本作ってお試しください。

**バーチャル2種はキー数が自由です。** Mobile は無料 6キー / Pro で最大64キー、形は
「大きな1ボタン（1×1）」から 8×8 まで。Virtual Stream Deck は行と列を指定して最大 8×8。
**「一覧にない機種」を選ぶときは、キーの数を下の欄で指定してください。**

**ダイヤルにも割り当てられます。** ダイヤル付き機種（`+` / `+XL` / Studio / GALLEON）を選ぶと
グリッドの下に現れ、1つにつき **左に回す / 押し込む / 右に回す** の3枠を持ちます。
実プロファイルから写した `com.elgato.streamdeck.keys.adaptor`（Action Trigger）で書き出します。
**押し込みだけ未検証**です — この機体にあったアダプタ3例すべてで中央が空だったため、
書き方の実例がありません。左右の回転は実例があります。タッチストリップは扱いません。

ダイヤルの割り当てはどのページでも同じです（フォルダごとに意味が変わるのは事故のもとと判断）。

デックを切り替えてキー数が減るとき、はみ出すボタンは確認のうえ外します
（放っておくと画面から消えたまま書き出されてしまうため）。

## 確かめてあること / 確かめていないこと

**実機から読み取って確認済み**

- ボタンの JSON 形式は、この PC の Stream Deck **7.5.1** で実際に動いている
  `/e no` ボタンをそのまま写したもの。ドキュメントからの推測ではありません。
- マルチアクション `com.elgato.streamdeck.multiactions.routine`、
  フォルダ `…profile.openchild`、戻る `…profile.backtoparent`、
  テキスト `…system.text` の `isSendingEnter` / `pastedText`、いずれも実測。
- manifest は UTF-8 **BOMなし**（Stream Deck 自身の書き方に合わせてある）。
- 書き出した zip を展開 → 構造検証（リンク解決・スロット上限・到達性）まで通してあります。
- `AnimationList.lua` のキーは `["a"]` と `['b']` の**両方の書き方**が混在しています
  （29件が単引用符）。両方拾うようにしてあります。片方だけだと黙って取りこぼします。

**実際の街のメニューを見て確認（2026-09-01・稼働中のサーバーで実測）**

`tools\grab-screen.ps1` で画面を撮り、直接読み取りました。

- **街のメニューは、選んだ項目の下に実際のコマンドを表示します**（`/e (boxdance)` の形）。
  表示名は英語のままで日本語化されていないので、**画面の文字をそのまま検索欄に打てます。**
- **共有エモートは `/e` ではなく `/nearby` でした。**実機で両方試した結果：
  `/e handshake` は**1人で**出る、`/nearby handshake` は**相手がいない**と出る。
  どちらも通りますが、94件すべてに相手側のアニメが記録されている以上、
  **相手ありきの `/nearby` が本来**です。94件を `/nearby` に変更しました。
- 画面に出た23件と同梱データを突き合わせ、**22件一致**。
  **その街の独自エモートは、見た範囲では出てきませんでした。**
- **動物エモートは人間のキャラで1件も反応しません**（実際に押して確認）。既定で隠す判断の裏付けです。
- メニューの分類（ダンス／動物／小道具／共有）は**Luaの区分そのもの**でした。
  ただし「共有ダンス」という入れ子があり、**これはLuaに存在しません**（`RP.` のテーブルは8つだけ）。

**実機で往復まで確認済み（2026-09-01）**

書き出し → 取り込み → Stream Deck から書き出し → 読み込み、を実際に通しました。

- **取り込みは成功し、中身は無傷。** マルチアクション4・`pastedText` 4・`NativeCode` 84(`T`) ×4、
  ラベルもそのまま。
- **アイコンは往復します。** 1,316B の PNG が
  `States[0].Image = "Images/<名前>.png"` ＋ ページ配下の `Images/` の形で保たれました。
- **`Device.UUID` は実機の UUID に書き換わります**（書き出しは匿名 GUID のまま）。
- **Stream Deck は取り込み時に `Pages` を書き換えます。**
  書き出し `Current` = ヌルGUID / `Default` = ルート → 取り込み後
  `Current` = 中身のあるページ / `Default` = **新規の空ページ**。
  そのため読み込み側は `Default` ではなく `Current` と `Pages[]` を見ます。
  ここを間違えると、自分で作ったプロファイルを読み戻して 0 件になります。
- **モバイル / バーチャルは最上位ページを複数持ちます**（実機のもので3つ、うち2つは空）。
  全部を順に読み、1つの並びとして扱います。
- ブラウザだけで `.streamDeckProfile` を読めます。`DecompressionStream('deflate-raw')` が
  [Baseline（2023年5月から全ブラウザ）](https://caniuse.com/mdn-api_decompressionstream)で、
  実プロファイルは全エントリが deflate 圧縮でした。

**確認していないこと**

- **チャットキーが `T` である前提。** おじさんの既存ボタンからの踏襲で、
  サーバー設定そのものは見ていません。違ったら「送信のしかた」から変更できます。
  ただし**押すと実際にコマンドが送られること自体は実機で確認済み**です
  （`/e` `/mood` `/walk` の3つともチャットに通りました）。
- **ダイヤルの押し込みの書き方。** 実例がないため推測です（実機での確認は所有者側で行います）。
- **共有ダンス**（メニューの入れ子）の中身とコマンド。Lua に該当する区分がありません。
- **小道具の色違いは扱いません。** `PropTextureVariations` が67件ありますが、
  ボタンからは既定の色になります。ある街ではコマンドの末尾に色の頭文字が付いて見えましたが、
  **書式として確かめられていない**ので、当てずっぽうで実装しません。
- **`/nearby` が原典にもあるか。** 現行で動くことは確認済みですが、原典側は未確認です。
- **`UI Stream Deck`（画面に出すデック）のキー数は未確認。** 既定 5×3 にしてありますが、
  一度も使われていないので実際の数は分かりません。合わなければ「列 / 行」を直してください。
- **Mac は対応しません。**FiveM クライアントは Windows 専用で
  （[Cfx 公式](https://docs.fivem.net/docs/client-manual/system-requirements/)が
  「Windows 8.1 / 10 / 11」のみ）、macOS 版は存在しません。
  Boot Camp や Parallels を使う場合も、キーを受け取るのは Windows です。
- **参加中サーバーのエモート一覧は取得できていません。**
  FiveM のリソースキャッシュ 4,377 ファイルを走査して 0 件。
  Cfx アセットエスクロー（暗号化）配布とみられます。
  登録されているエモート一覧 1,851 件は **rpemotes-reborn の公式リポジトリ（master）** のもので、
  日本語化ぶんや独自追加（「F ○○」系）は含まれません。
  → 対策はゲーム内「お気に入り」からの取り込み（上記②）。
- ゲームログからわかった、この街が積んでいるエモート系リソース：
  `rpemotes-reborn` / `rpemotes` / `Pazeee_FireworkEmotePack` / `kaykaymods_props`。
  1つのリソースではなく**複数の寄せ集め**なので、この一覧とのズレは大きいと見てください。
- FiveM のクライアント KVP は `%APPDATA%\CitizenFX\kvs` にあります（FiveM.app の外）。
  2026-08-26 時点でお気に入りは**未保存**（ストアの全8キーにエモート関連なし）。
  ストア自体は読めることを実データで確認済み。
- **書き出し形式は本物のエクスポートと突き合わせ済み**（`tools\verify-export.ps1` が
  `STRUCTURE MATCHES`）。`package.json` の有無・`Profiles/` の階層・`FormatVersion`・
  `Pages.Current`・BOM無し・`RequiredPlugins` の網羅まで一致します。
